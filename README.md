# CareerBridge – Student Recruitment Portal

CareerBridge is a web-based application designed to simplify and automate the college placement and recruitment process. It provides a centralized platform where students can explore job opportunities, apply for placement drives, check eligibility, and track their application status. Placement officers can manage companies, job openings, student applications, and recruitment activities efficiently.

---

## 🚀 Features

### 👨‍🎓 Student Module
- Student Registration and Login
- Student Profile Management
- Upload and Manage Resume
- Browse Available Job Opportunities
- Automatic Eligibility Checking
- Apply for Placement Drives
- Track Application Status
- View Interview Schedules
- Receive Notifications

### 👨‍💼 Admin Module
- Admin Login and Dashboard
- Manage Student Records
- Add, Update and Delete Companies
- Manage Job Opportunities
- Define Placement Eligibility Criteria
- View and Manage Applications
- Shortlist or Reject Candidates
- Schedule Interviews
- Update Student Selection Results
- Generate Placement Reports

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Navigate to the Project

```bash
cd CareerBridge
```

### 3. Frontend Setup

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash

```

Start the React development server:
